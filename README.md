# Agentify

Agentify is a tool that lets any website become ***agentic***. It lets website write to folders, read content of folder, execute commands, read files etc. all with your permission!

## why it's better than models in sandbox (like claude or chatgpt)?

| Comparison<br>object | Sandbox                                                                                | Agentify                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Memory               | Model X can't read Model Y's `skills.md` or `soul.md` to match its style               | All models share a unified folder containing all Markdown files                                  |
| Power                | It can create files and execute but in sandbox and you need to manually copy artifacts | All on your computer. all files created and services started are accesible from explorer/browser |
| Cost                 | Paid/Free                                                                              | Free                                                                                             |
| Security             | Very secure                                                                            | Can be unsecure if you click all permissions without looking                                     |
| Open source          | No                                                                                     | Yes (MIT)                                                                                        |
